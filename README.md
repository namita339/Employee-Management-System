# Employee Management System

## 📌 Project Overview
The Employee Management System is a Java-based desktop application developed using Java Swing and MySQL. It enables administrators to manage employee records efficiently with secure login authentication and database integration.

This project demonstrates practical implementation of OOP concepts, JDBC connectivity, and CRUD operations.

## 🛠 Tech Stack
- Java
- Java Swing (GUI)
- MySQL
- JDBC
- Object-Oriented Programming (OOP)
## Features
-  Secure Login Authentication
-  Add Employee Records
-  Update Employee Details
-  Delete Employee Records
-  View Employee Data
-  Database Connectivity using JDBC
-  Input Validation and Error Handling

## 🗄 Database Design
The application uses a relational database structure with:

- Admin Table (Login credentials)
- Employee Table (Employee details)
## ▶ How to Run
1. Clone this repository
2. Open in IntelliJ / Eclipse
3. Create MySQL database
4. Update database credentials in source code
5. Run the main Java file
